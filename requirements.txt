# Quantum-Ai-PCB-Builder Python Dependencies
#
# Core application dependencies:
# The base implementation uses only Python 3.11+ standard library.
# No external packages are required for basic functionality.
#
# Optional dependencies for extended functionality:
#
# To enable OpenAI GPT integration:
#   pip install openai>=1.0.0
#
# To enable Claude integration:
#   pip install anthropic>=0.7.0
#
# To enable RabbitMQ message queue:
#   pip install pika>=1.3.0
#
# To enable Redis result backend:
#   pip install redis>=5.0.0
#
# For production API deployment:
#   pip install uvicorn>=0.24.0 fastapi>=0.104.0
#
# Note: The stub implementations provided work without these dependencies.
# Install the appropriate packages when integrating with real services.
